# Στέργιος Χατζηκυριακίδης — Κείμενα

Προσωπικός ιστότοπος με λογοτεχνικά κείμενα.
Ζωντανά στο: **https://stergioscha.github.io/literature/**

## Δομή

```
index.html            ← αρχική σελίδα (η λίστα με τα κείμενα)
assets/
  site.css            ← η εμφάνιση όλου του ιστότοπου (μία φορά, για όλα)
  reader.js           ← κίνηση, θέμα, μέγεθος γραμμάτων
texts/
  xlorini.html        ← «Χλωρίνη δώδεκα κιλά»
  _TEMPLATE.html      ← αντίγραφο-πρότυπο για νέα κείμενα
```

## Πώς προσθέτω ΝΕΟ κείμενο (2 βήματα)

**1) Φτιάξε τη σελίδα του κειμένου**
- Πάρε αντίγραφο του `texts/_TEMPLATE.html` και δώσ' του όνομα με λατινικά,
  χωρίς κενά, π.χ. `texts/nyxta.html`.
- Άλλαξε τον τίτλο και επικόλλησε το κείμενο (κάθε παράγραφος μέσα σε `<p> … </p>`).

**2) Βάλ' το στη λίστα της αρχικής**
- Άνοιξε το `index.html` και βρες το `const TEXTS = [`.
- Αντίγραψε ένα μπλοκ `{ … }`, βάλ' το πρώτο-πρώτο και συμπλήρωσε
  `title`, `kind`, `blurb`, `minutes`, `href` (π.χ. `"texts/nyxta.html"`).

Τέλος. Το χρώμα, οι γραμματοσειρές και όλη η εμφάνιση έρχονται αυτόματα
από το `assets/site.css`.

## Αλλαγή εμφάνισης παντού

Άλλαξε μία φορά το `assets/site.css` (π.χ. τα χρώματα στο `:root` πάνω-πάνω)
και ενημερώνονται όλα τα κείμενα μαζί.
